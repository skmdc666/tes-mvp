# Onboarding Guide for New Team Members

Welcome to The Expanse Solutions (TES)! This guide will help you get up to speed quickly.

## Before Your First Day

### Pre-Onboarding (1 Week Before)

1. **Send welcome email** with:
   - Team member names and photos
   - GitHub repository link
   - Slack workspace invite
   - Calendar invites for first-day meetings

2. **Send equipment list**:
   - Laptop specifications
   - Software licenses needed
   - Access credentials (generate and secure)
   - VPN setup instructions (if applicable)

3. **Create accounts**:
   - GitHub account and repository access
   - Slack workspace
   - AWS console access (engineers only)
   - Deployment platforms (Railway/AWS)

### Hardware Setup

Ensure the following is available on day 1:
- [ ] Laptop (MacBook Pro 14" or equivalent)
- [ ] External monitor (optional)
- [ ] Mouse and keyboard
- [ ] USB-C charging cable
- [ ] WiFi credentials
- [ ] VPN setup (if remote)

## First Week Meeting Schedule

  - What did you do yesterday?
  - What are you doing today?
  - Any blockers?

### Tuesday
- **2:00 PM**: 1-on-1 with Manager (30 min)
  - How is onboarding going?
  - Any questions or concerns?
  - Set expectations for first month

### Wednesday
- **10:00 AM**: Code Review Walkthrough (30 min)
  - How we review code
  - What we look for
  - Ask questions about existing PRs

### Thursday
- **3:00 PM**: Pair Programming Session (60 min)
  - Work on a real issue with a team member
  - Learn team's development practices

### Friday
- **4:00 PM**: Team Retro + Casual Chat (30 min)
  - How was your first week?
  - Any feedback on onboarding?
  - Casual team hangout

## Onboarding Buddy System

Each new member is paired with an onboarding buddy (usually a senior engineer).

### Buddy Responsibilities
- Available for questions
- Helps debug local setup
- Reviews first pull request
- Explains team norms
- Answers "stupid questions" patiently
- Check in daily during first week

### How to Reach Your Buddy
- Slack: Direct message anytime
- Pair programming: Scheduled sessions
- Ad-hoc help: Just ask!

## First Month Goals

### Week 1
- Setup and familiar with codebase
- Make first contribution
- Know team and processes

### Week 2-3
- Complete second meaningful contribution
- Understand major feature in depth
- Start owning small areas

### Week 4
- Onboarding complete

## FAQ

**Q: What if I get stuck?**
A: Ask your buddy or in #engineering channel. No question is too small.

**Q: When do I have my first solo task?**
A: Usually by end of week 2, after your setup is solid.

**Q: What if I disagree with how we do something?**
A: Great! Bring it up. We value constructive feedback.

**Q: How long until I'm productive?**
A: By week 2-3, you should be able to work independently on small tasks.

**Q: What about remote work?**
A: Check with your manager for company remote policy.
